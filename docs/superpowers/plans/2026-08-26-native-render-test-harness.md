# Native Render Test Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `@Tag("native")`-gated JUnit suite (`WidgetNativeRenderTest`) that boots one Flutter engine per JVM, drives every widget × variant through it, and asserts the widget renders (Element in tree, RenderBox `size > 0`, no captured `FlutterError`). Extend the Dart generator to emit the variant catalog into `src/test/java` so the hand-maintained `mountableWidgets()` list retires.

**Architecture:** Shared engine on a daemon thread; per-variant swap through a mutable `Supplier<Widget>` on `HotReloadRoot` triggered by a new `Starter_requestRebuild()` C export. Post-frame callback in Dart captures a JSON depth-first snapshot of the element tree and pushes it plus the `frameId` to Java via a new FFM upcall. `FlutterError.onError` handler streams captured exceptions up the same way, tagged by `frameId`. Variants come from a new generator emitter (`variants_gen.dart`) that produces `<Widget>Variants.java` + `WidgetVariantsRegistry.java` under `ewt.api/src/test/java/dev/equo/ewt/support/variants/`.

**Tech Stack:** Java 22 (Foreign Function & Memory API), Dart (Flutter 3.35.7 plugin), C (libStarter), jextract 25 for FFM bindings, JUnit 5 (`@ParameterizedTest`, `@Tag`), GitLab CI + xvfb.

**Spec:** `docs/adr/0009-native-render-test-harness.md`

```dart
// widgets/lib/engine_hooks.dart
import 'dart:convert';
import 'dart:ffi';
import 'package:ffi/ffi.dart';
import 'package:flutter/foundation.dart';
import 'package:flutter/widgets.dart';
import 'widgets_bindings_generated.dart';

int _frameId = 0;
bool _captureNext = false;

/// Installs post-frame snapshot capture, FlutterError forwarding, and a
/// rebuild handler that mutates [rootHolder]. Call once at engine boot.
Future<void> attachEngineHooks({
    required ValueNotifier<Widget> rootHolder,
    required int Function() nextFrameId,
}) async {
  // 1. Post-frame: capture snapshot when armed.
  WidgetsBinding.instance.addPersistentFrameCallback((_) {
    if (!_captureNext) return;
    _captureNext = false;
    final id = _frameId;
    final json = _captureTreeSnapshot();
    final bytes = utf8.encode(json);
    final Pointer<Utf8> p = bytes.allocateAsUtf8();
    try {
      callPostFrameCallback(id, p.cast(), bytes.length);
    } finally {
      calloc.free(p);
    }
  });

  // 2. FlutterError capture.
  FlutterError.onError = (details) {
    final Pointer<Utf8> pKind = details.exception.runtimeType.toString().toNativeUtf8();
    final Pointer<Utf8> pMsg  = details.exceptionAsString().toNativeUtf8();
    final Pointer<Utf8> pStk  = (details.stack ?? StackTrace.empty).toString().toNativeUtf8();
    try {
      callFlutterErrorCallback(_frameId, pKind.cast(), pMsg.cast(), pStk.cast());
    } finally {
      calloc.free(pKind); calloc.free(pMsg); calloc.free(pStk);
    }
  };

  // 3. Rebuild handler: bump frameId, arm capture, mutate root, mark dirty.
  final rebuildFn = Pointer.fromFunction<Void Function()>(_onRebuildRequested);
  setRebuildHandler(rebuildFn);
}

void _onRebuildRequested() {
  _frameId = nextFrameId();
  _captureNext = true;
  // Root swap actually happens via a ValueNotifier consumed by a HotReloadRoot
  // wrapper widget; setting it schedules a rebuild.
  _rootHolderRef?.value = _pendingRoot ?? _rootHolderRef!.value;
}

String _captureTreeSnapshot() {
  final root = WidgetsBinding.instance.rootElement;
  if (root == null) return '[]';
  final sb = StringBuffer('[');
  var first = true;
  void visit(Element e, int depth) {
    if (!first) sb.write(','); first = false;
    final ro = e.renderObject;
    final hasSize = ro is RenderBox && ro.hasSize;
    sb.write('{"t":"${e.widget.runtimeType}","d":$depth,"r":${ro != null}');
    if (hasSize) {
      sb.write(',"s":true,"w":${(ro).size.width},"h":${(ro).size.height}');
    }
    sb.write('}');
    e.visitChildren((c) => visit(c, depth + 1));
  }
  visit(root, 0);
  sb.write(']');
  return sb.toString();
}
```

```java
package dev.equo.ewt;

import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicLong;

public final class PostFrameNotifier {
    private final AtomicLong lastFrameId = new AtomicLong();
    private final ConcurrentLinkedQueue<Pending> waiters = new ConcurrentLinkedQueue<>();

    private record Pending(long afterFrameId, CompletableFuture<PostFrame> fut) {}

    public long lastFrameId() { return lastFrameId.get(); }

    public CompletableFuture<PostFrame> awaitFrameAfter(long frameId) {
        var fut = new CompletableFuture<PostFrame>();
        waiters.offer(new Pending(frameId, fut));
        return fut;
    }

    /** Invoked from the FFM upcall on a native thread. */
    public void onFrame(long frameId, String snapshotJson) {
        lastFrameId.set(frameId);
        var pf = new PostFrame(frameId, snapshotJson);
        waiters.removeIf(p -> {
            if (frameId > p.afterFrameId) { p.fut.complete(pf); return true; }
            return false;
        });
    }
}
```

```java
package dev.equo.ewt;

import dev.equo.ewt.ffm.*;
import java.lang.foreign.*;
import java.util.concurrent.*;
import java.util.function.Supplier;

public final class EngineHandle {
    private final Supplier<Widget> rootSupplier;
    private final PostFrameNotifier postFrames;
    private final FlutterErrorCollector errors;
    private final CompletableFuture<Void> firstFrame = new CompletableFuture<>();
    private final Arena arena = Arena.ofShared();

    public EngineHandle(Supplier<Widget> rootSupplier,
                        PostFrameNotifier postFrames,
                        FlutterErrorCollector errors) {
        this.rootSupplier = rootSupplier;
        this.postFrames   = postFrames;
        this.errors       = errors;
    }

    public CompletableFuture<Void> firstFrameReady() { return firstFrame; }

    public void run() {
        // Build buildWidgetTreeFn (reuse App's dispatcher shape).
        MemorySegment buildFn = buildWidgetTreeFn.allocate((factories, regionId) -> {
            try {
                WidgetConstructors.instance.set(WidgetFactories.reinterpret(factories, arena, ms -> {}));
                Widget w = rootSupplier.get().build();
                return ((NativeObj) w).getId();
            } catch (Exception e) { throw new RuntimeException(e); }
        }, arena);

        // Post-frame upcall — wraps PostFrameNotifier + first-frame completion.
        MemorySegment postFn = postFrameFn.allocate((frameId, snapshotPtr, snapshotLen) -> {
            String json = snapshotPtr.reinterpret(snapshotLen).getString(0, java.nio.charset.StandardCharsets.UTF_8);
            postFrames.onFrame(frameId, json);
            if (!firstFrame.isDone()) firstFrame.complete(null);
        }, arena);

        // Flutter-error upcall.
        MemorySegment errFn = flutterErrorFn.allocate((frameId, kindPtr, msgPtr, stkPtr) -> {
            errors.onError(new FlutterErrorRecord(frameId,
                kindPtr.getString(0), msgPtr.getString(0), stkPtr.getString(0)));
        }, arena);

        MemorySegment opts = StarterOpts.allocate(arena);
        StarterOpts.buildWidgetTree(opts, buildFn);
        StarterOpts.onPostFrame(opts, postFn);
        StarterOpts.onFlutterError(opts, errFn);
        int r = StarterBridge.startApp(opts);
        if (r != 0) throw new RuntimeException("startApp returned " + r);
    }

    public void requestRebuild()  { StarterBridge.Starter_requestRebuild(); }
    public void requestShutdown() { StarterBridge.Starter_requestShutdown(); }
}
```

```dart
// generator/lib/type_samples.dart
import 'package:analyzer/dart/element/type.dart';

class TypeSamples {
  String? sampleCodeFor(DartType t) {
    if (t.isDartCoreString) return '"hello"';
    if (t.isDartCoreInt)    return '1';
    if (t.isDartCoreDouble) return '1.0';
    if (t.isDartCoreBool)   return 'true';
    final n = t.element?.name;
    switch (n) {
      case 'Color':       return 'Color(0xff0000ff).build()';
      case 'EdgeInsets':  return 'EdgeInsets_all(8.0).build()';
      case 'TextStyle':   return 'TextStyle.builder().build()';
      case 'Duration':    return 'Duration.milliseconds(200).build()';
      case 'Offset':      return 'Offset.zero()';
      // …extend as the emitter hits new required types
    }
    if (t is InterfaceType && t.element is EnumElement) {
      final vals = (t.element as EnumElement).fields.where((f) => f.isEnumConstant).toList();
      if (vals.isNotEmpty) return '${t.element!.name}.${vals.first.name}';
    }
    if (t is FunctionType) return _lambdaFor(t);
    if (t is InterfaceType && t.isDartCoreList) {
      final inner = t.typeArguments.first;
      final innerSample = sampleCodeFor(inner);
      if (innerSample == null) return null;
      return 'List.of($innerSample)';
    }
    return null;
  }

  String? boundaryCodeFor(DartType t) {
    if (t.isDartCoreString) return '""';
    if (t.isDartCoreInt)    return '0';
    if (t.isDartCoreDouble) return '0.0';
    if (t.isDartCoreBool)   return 'false';
    if (t is InterfaceType && t.isDartCoreList) return 'List.of()';
    // Fall back to sample for complex types (no meaningful boundary).
    return sampleCodeFor(t);
  }

  bool hasSampleFor(DartType t) => sampleCodeFor(t) != null;

  String _lambdaFor(FunctionType f) {
    final arity = f.parameters.length;
    if (arity == 0) return '() -> {}';
    final args = List.generate(arity, (i) => '_a$i').join(', ');
    return '($args) -> {}';
  }
}
```

- [ ] **Step 4.3.1: Sketch emitter shape (`VariantsEmitter`)**

Per-widget-file emission logic. For each `@Builder.Factory` on the widget:
1. Collect required params (via existing `Params.parameters.where((p) => p.isRequired)`).
2. If any required param has no sample in `TypeSamples`, log `stderr.writeln('variants: skipping ${name} - no sample for ${t}')` and skip the widget entirely.
3. Emit `<factory>_required()` — required params only.
4. Emit `<factory>_allSet()` — required + `.<opt>(sample)` for each optional. Skip optionals whose types have no sample (log).
5. Emit `<factory>_boundary()` — required + `.<opt>(boundary)` per optional; if `boundary == sample`, still emit (harmless duplicate coverage).
6. Emit `<factory>_nullExplicit()` — required only (Optional.empty is the default); if there are no optionals, skip (equivalent to `_required`).
7. Emit `<factory>_callbackWired()` — required + `.<opt>(lambda)` for each optional whose type is a FunctionType. Skip if there are no callback opts.
8. Emit the `EXPECTATIONS` map only for `_allSet` and `_boundary` (the ones we can meaningfully assert on).

Wrap in `scaffoldFor(widgetName)` when applicable.

Also emit a companion `WidgetVariantsRegistry.java` that lists every `(widgetName, variantLabel, methodRef, expectations)` entry.

Full skeleton (~150 lines Dart); implement following the pattern in `generator/lib/emit/widget_gen.dart` for how it writes Java files with header + class + methods.
